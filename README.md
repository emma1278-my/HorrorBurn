
## 🌐 アプリ名　Horror Burn

https://horrorburn.com
　
## 👻 概要
2012年にウエストミンスター大学が行った研究によると、90分のホラー映画を観ると、約113カロリーを消費することが明らかになりました。これは30分間のウォーキングに相当するカロリー消費量です。この現象は、恐怖や緊張による心拍数の上昇と基礎代謝の増加によって引き起こされます。
本アプリは、ホラー映画の持つ恐怖と興奮を活用して、ダイエット中のモチベーション維持と適度なカロリー消費をサポートします。ホラー映画が好きな方には、映画を楽しみながらダイエットができるサービスを提供します。また、ダイエット中の方にとっては、ダイエットの辛い時間をホラー映画鑑賞という時間に変えることで、継続しやすくなります。



## 👻 サービス概要
- アプリに目標体重と目標期間を設定します。
- 90分のホラー映画を観ると、約113カロリーを消費することを利用し、減少すべきカロリーを算出し、ユーザーにホラー映画視聴本数を提案します。
- 視聴した映画や消費カロリーはアプリに記録され、進捗が追跡されます。

  

## 👻 このサービスへの思い・作りたい理由
ダイエットは、自分の健康と向き合う大切な時間ですが、無理をしてしまうと逆効果になることもあります。私自身、過去にダイエットに気負いすぎて拒食症になった経験があります。このアプリは、そんな辛い経験を乗り越えて、気楽にダイエットを楽しむ手助けをしたいという思いから作りました。
ダイエットは本来健康になるためにするものであり、決して苦しいものではなく、楽しみながら続けられるものです。ホラー映画を観てドキドキしながら、無理せず、自分のペースで、楽しみながら健康的な生活を目指していくことを目標にしています。



## 👻 ユーザー層について
- ホラー映画を鑑賞する人:
  ダイエットというさらなる付加価値を提供します。
- ダイエット中の人:
  楽しみながらダイエットを続けることができます。楽しさと効果を両立させることで、モチベーションを高め、ダイエットの成功をサポートします。
- 映画鑑賞に時間を割くことに罪悪感を感じる人:
  ダイエットを兼ねていると考えれば安心してホラー映画を楽しむことができます。これにより、新たにホラー映画鑑賞を始めるきっかけにもなると考えています。

視聴した映画・消費したカロリーを共有できます。



## 👻 サービスの差別化ポイント・推しポイント
- ホラー映画とダイエットの組み合わせ:
一般的なダイエットアプリやフィットネスアプリは、運動や食事制限を中心にしていますが、本アプリはホラー映画の視聴をダイエットに取り入れるというユニークなアプローチを採用しています。
- 楽しみながらのカロリー消費:
ダイエットが辛いものではなく、楽しみながら行えるという点は、多くのダイエットユーザーにとって魅力的なことなのではないかと考えます。ホラー映画好きのユーザーにとって、好きな映画を観ることで健康管理ができます。
- 目標設定と具体的な提案:
目標体重と期間を設定し、その目標に達するために必要なホラー映画の視聴本数を提案する機能は、ユーザーにとって具体的で分かりやすいガイドラインとなります。これにより、ユーザーは自分の進捗を明確に把握でき、モチベーションの維持が安易になります。
- 進捗の追跡と記録:
視聴した映画や消費カロリーを記録し、進捗を追跡できる機能は、自身の努力の成果を目に見える形で確認できるため、達成感を感じやすくなります。
- コミュニティ機能:
ユーザー同士が観た映画をXで共有できます。他のユーザーと交流し、励まし合うことで、ダイエットの成功率が高まります。

## 👻 機能の実装方針予定
- The Movie Database (TMDb) API： 映画検索機能：ユーザーがホラー映画を検索し、タイトル等の詳細情報を取得できるようにします。
- Goolge API： Google Sign-Inを使用してユーザーがログインする場合に使用します。
